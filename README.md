# Compta Asso – téléchargements

**Compta Asso** est un logiciel de comptabilité pour les associations d'Afrique centrale (Gabon d'abord), conforme au **SYCEBNL**, le système comptable des entités à but non lucratif de l'OHADA. Il fonctionne **sans Internet** et gère plusieurs associations, chacune dans son propre dossier. Profils : association générale, cultuelle ou culturelle.

> Les versions **0.x** sont des versions d'essai : le plan de comptes propre aux associations doit encore être validé par un expert-comptable. Utilisez-les pour vous former ou en parallèle de votre comptabilité habituelle.

Ce dépôt contient **uniquement** les fichiers d'installation et les fichiers de mise à jour du logiciel. Il ne contient ni code source, ni donnée d'association.

## Télécharger

Ouvrez la page **[Releases](../../releases/latest)** (dernière version), puis, en bas, la rubrique **Assets** :

| Votre ordinateur | Fichier à télécharger |
| --- | --- |
| Windows 10 ou 11 (64 bits) | `Compta-Asso-<version>-installeur-windows.exe` |
| Mac à puce Apple (M1, M2, M3…) | `Compta-Asso-<version>-mac-puce-apple.dmg` |
| Mac à processeur Intel | `Compta-Asso-<version>-mac-intel.dmg` |

Sur Mac : menu Pomme → « À propos de ce Mac » indique « Puce Apple » ou « Processeur Intel ».

Les autres fichiers (`latest.yml`, `latest-mac.yml`, `.blockmap`) servent aux mises à jour automatiques : vous n'avez pas à les télécharger. Le fichier `SHA256SUMS.txt` donne l'empreinte de chaque installeur, pour vérifier qu'il n'a pas été modifié.

## Installer

Le logiciel n'est pas encore « signé » : Windows et macOS affichent un avertissement au premier lancement. La marche à suivre, pas à pas, est dans le **guide** livré avec le logiciel (menu **Aide**, chapitre 2 « Installer et ouvrir le logiciel »), aussi disponible en PDF dans le dossier du logiciel installé.

## Mises à jour

- **Windows** : le logiciel vous prévient quand une nouvelle version est publiée ici. Il ne télécharge **rien sans votre accord**, et fait une sauvegarde de vos dossiers avant d'installer.
- **Mac** : le logiciel vous prévient et ouvre cette page ; installez la nouvelle version vous-même, comme la première fois.

Vos dossiers `.compta`, vos sauvegardes et vos réglages sont toujours conservés.
